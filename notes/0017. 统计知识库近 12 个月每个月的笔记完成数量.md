## 1. 本节内容

- 统计知识库近 12 个月每个月的笔记完成数量

## 2. 评价

完成数写在 `tnotes.json` 的 `stats.completedNotesCount`，不再写旧的 `.tnotes.json`。

```json
"stats": {
  "enabled": true,
  "completedNotesCount": {
    "25.10": 9,
    "25.11": 14,
    "25.12": 15,
    "26.09": 15
  }
}
```

`pnpm tn:update`（`tnotes-kb update`）会按 git 历史和 `TOC.md` 的 `- [x]` 回填这个对象。

可以集成图表看近一年趋势：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-12-14-17-05-15.png)

实现要点：

```txt
1. 用 git 历史看每个月「已完成」笔记数（按笔记编号去重）
2. TOC.md 里 - [x] 表示完成，- [ ] 表示未完成
3. 统计窗口写入 tnotes.json → stats.completedNotesCount（键为 YY.MM）
```
