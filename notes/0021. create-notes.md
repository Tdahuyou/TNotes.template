## 1. 本节内容

- 新建笔记、新建知识库

## 2. 评价

`tnotes --create-notes` / `tn:create-notes` 已去掉。新建走 Desk，或命令行 `tnotes-kb init`。

## 3. 在已有知识库里新建笔记

1. Desk 打开该知识库。
2. 在侧栏新建笔记或分组。
3. 编号按当前最大号 +1 分配，例如已有 `0041` 则下一篇是 `0042`。
4. 文件落在 `notes/NNNN. 标题.md`，同时写入 `TOC.md`。

不要手改已有笔记的四位编号。

## 4. 新建知识库

Desk「新建知识库」对话框（选项默认全关）：

| 选项 | 作用 |
| --- | --- |
| 文件夹名 | 磁盘目录名，须匹配 `^[A-Za-z0-9._-]{1,100}$` |
| 显示名称 | Desk 列表标题，默认与文件夹名相同 |
| 添加 CLI / package.json | 方便 `pnpm tn:dev` / `tn:build` |
| 添加 GitHub Pages 工作流 | 写入 `deploy.yml`，并附带 package.json |
| 生成 README.md | 仓库首页说明，不是引导笔记 |
| 初始化 Git 仓库 | 在该目录 `git init` |

最小结果：`tnotes.json`、`TOC.md`、`notes/0001. 开始使用.md`、`.gitignore`、`.gitattributes`。

命令行等价：

```bash
tnotes-kb init TNotes.demo --title demo
tnotes-kb init TNotes.demo --package-json --github-pages --readme --git-init
```
