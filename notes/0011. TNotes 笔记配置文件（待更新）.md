## 1. 概述

新架构里配置分两层：

- 知识库：根目录 `tnotes.json`
- 笔记：每个 `notes/NNNN. 标题.md` 顶部的 YAML frontmatter

已经没有「每个笔记目录一份 `.tnotes.json`」。旧字段里的 `yuque` / `bilibili` 不再读取。

## 2. `tnotes.json` 常见字段

| 字段 | 作用 |
| --- | --- |
| `name` | 仓库名，如 `TNotes.docs` |
| `title` | Desk 列表和站点显示名 |
| `description` | 一句话简介 |
| `icon.src` | 图标 URL 或 `../assets/.tn-kb-icon.*` |
| `port` | Desk 预览 / `tnotes-ssg` 端口（本库 `10107`） |
| `pageUrl` | GitHub Pages 地址 |
| `repositoryUrl` | GitHub 仓库地址 |
| `base` | 站点 base，Pages 上一般是 `/TNotes.docs/` |
| `home` | 首页用哪一篇笔记编号；默认 TOC 第一篇 |
| `discussions` | 是否开 giscus |
| `stats.enabled` | 是否允许 `tnotes-kb update` 回填完成数 |
| `stats.completedNotesCount` | `YY.MM` → 当月已完成笔记数 |

可在 Desk 的知识库配置页改，也可以直接改文件。

## 3. 笔记 frontmatter

只保留白名单字段：

```md
---
id: 53e43306-98a7-4a0a-a84f-bf37a435d072
description: 给 NotesTable 看的一句话
---
```

- `id`：稳定 UUID，giscus 评论映射键。迁移时原样带过来，不要重生成。
- `description`：NotesTable 展示；可空。

完成态不在 frontmatter 里，只看 `TOC.md` 的 `- [x]` / `- [ ]`。

## 4. 旧的 `yuque` 字段

早期每篇笔记的 `.tnotes.json` 里有过 `yuque` 数组，用来挂语雀链接。新模型不再读这个字段。需要外链时直接写在正文里即可。
