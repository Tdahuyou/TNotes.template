## 1. 本节内容

本节是 Mermaid 的基本使用。Desk 和 `tnotes-ssg` 都集成了 mermaid，笔记里直接写围栏即可。

## 2. mermaid 组件如何使用？

和 [mermaid][1] 要求的语法一致。

输入：

````md
```mermaid
flowchart LR
  Start --> Stop
```
````

输出：

```mermaid
flowchart LR
  Start --> Stop
```

会在鼠标悬停在图表上时，显示相关控制按钮：
