## 1. 本节内容

- 知识库 `package.json` 里还剩哪些脚本

## 2. 评价

脚本已经抽到 npm 包，不再塞在每个仓库的 `.vitepress/tnotes` 里。有 Desk 的话，多数日常操作不用开终端。

## 3. 当前脚本

```json
{
  "scripts": {
    "tn:update": "tnotes-kb update",
    "tn:build": "tnotes-ssg build",
    "tn:dev": "tnotes-ssg dev",
    "tn:preview": "tnotes-ssg preview"
  },
  "devDependencies": {
    "@tnotesjs/kb": "^0.2.1",
    "@tnotesjs/ssg": "^0.1.2"
  }
}
```

| 命令 | 描述 | 谁在用 |
| --- | --- | --- |
| `tn:update` | 按 TOC 完成态 + git 历史回填 `stats.completedNotesCount` | CI、本地统计 |
| `tn:build` | 静态站 → `.tnotes/dist` | CI Pages、本地验收 |
| `tn:dev` | 无 Desk 时的站点热更新 | 可选 |
| `tn:preview` | 预览已构建产物 | 可选 |

## 4. 已删除的旧命令

`tn:new`、`tn:push` / `tn:pull` / `tn:sync`、`tn:pushAll` / `tn:pullAll` / `tn:syncAll`、`tn:merge` / `tn:distribute`、`tn:tempSync`、`tn:sync-scripts`、`tn:fix-timestamps`、`tn:help`、`tn:update-completed-count`、`tn:dev:safe` / `tn:update:safe`。

| 旧能力 | 现在怎么做 |
| --- | --- |
| 新建笔记 / 知识库 | Desk，或 `tnotes-kb init` |
| 推送 / 拉取 | 普通 `git`，或 Desk 的 git 操作 |
| 完成数统计 | `tn:update`（已包含旧的 `update-completed-count`） |
| 同步 core 脚本 | 不再需要；依赖 registry 上的 kb / ssg |
| VSCode Tasks 调 tnotes | 可删。编辑请用 Desk |

## 5. 创建知识库时要不要 package.json？

Desk 预览**不需要** `package.json`。只有打算本地/CI 跑 `tnotes-ssg` 或开 GitHub Pages 时才勾选「添加 CLI / package.json」。
