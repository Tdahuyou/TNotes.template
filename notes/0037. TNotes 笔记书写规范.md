## 1. 本节内容

- TNotes 笔记书写规范

## 2. 评价

这一章管「一篇笔记怎么落盘」，不是文风指南。

<NotesTable :ids="['0038', '0027']"/>

## 3. 文件

- 一篇笔记一个文件：`notes/0001. 标题.md`
- 编号四位、只增不改
- 标题可以改（Desk 重命名），编号不要手改
- 图片放到库级 `assets/`，正文写 `../assets/文件名`
- 粘贴到本地的图片文件名：`${index}-${YY}-${MM}-${DD}-${HH}-${mm}-${ss}`，例如 `0008-26-09-08-14-22-01.png`（`index` 是笔记四位编号）

## 4. frontmatter

只放 `id`、`description`。完成态写在 `TOC.md`。

HTML 注释 `<!-- -->` 只在源码视图有意义；Desk 视觉编辑里不会显示，也不要靠它当正文。

## 5. 目录

分组和顺序只认 `TOC.md`：

```md
- [x] 0001. TNotes 简介
  - [x] 0014. 分仓库模式
- TNotes 命令
  - [ ] 0020. build
```

不要再维护根目录 `README.md` 当目录源，也不要手写 `sidebar.json`。
