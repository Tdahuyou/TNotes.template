## 1. 本节内容

- 怎么看命令帮助

## 2. 评价

`tnotes --help` 已随 `@tnotesjs/core` 一起停用。现在是两个包、两套 CLI。

```bash
tnotes-kb --help
tnotes-ssg --help
```

知识库里如果装了依赖，也可以：

```bash
pnpm exec tnotes-kb --help
pnpm exec tnotes-ssg --help
```

Desk 本身没有「help 命令」；按钮和配置页就是入口。
