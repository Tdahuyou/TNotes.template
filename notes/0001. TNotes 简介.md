## 3. TNotes 是什么？

![TNotes](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-06-02-19-14-40.png) {w=50% align=center}

[TNotes](https://tnotesjs.github.io/TNotes/)（Tdahuyou の Notes）是一套用来写、管、发布个人开源知识库的免费工具。日常编辑走 **Desk**，站点构建走 **`@tnotesjs/ssg`**，目录和配置走 **`@tnotesjs/kb`**。渲染组件在 **`@tnotesjs/ui`**。评论仍用 [giscus][3]，发布仍用 [GitHub Pages][2]。

但凡是在 TNotes 中能看到的内容，均已开源在 [tnotesjs github][5] 上，有需要的可自行 clone。

TNotes 诞生时间是 -> `24.08.28`。`26.09` 起新知识库不再依赖 VitePress / `@tnotesjs/core`。

## 4. TNotes 中的「知识库」、「笔记」指的是什么？

- 「知识库」本质上就是一个简单的 git 仓库，根目录有一份 `tnotes.json`。
- 「笔记」是 `notes/` 下从 `0001` 起编号的**平铺单文件**，例如 `notes/0001. TNotes 简介.md`。编号只增不改、不重排。

## 5. 「知识库」基本结构是？

这里以当前 `TNotes.docs` 为例：

```bash
# .
# ├── tnotes.json          # 库名、标题、端口、Pages 地址、统计、评论开关
# ├── TOC.md               # 分组、顺序、完成态（- [x] / - [ ]）的唯一真相源
# ├── notes/               # 平铺笔记
# │   ├── 0001. TNotes 简介.md
# │   ├── 0002. TNotes 公式支持.md
# │   └── ……
# ├── assets/              # 库级图片，文件名带笔记编号；笔记里写 ../assets/...
# ├── package.json         # 可选：tn:update / tn:build / tn:dev / tn:preview
# └── .github/workflows/deploy.yml   # 可选：tnotes-ssg → .tnotes/dist → Pages
```

日常读写请用 Desk 打开这个目录。不必再维护 `.tnotes.json`、`sidebar.json`、`.vitepress/`。

## 6. TNotes 有什么用？

### 6.1. 用 Desk 管理笔记

- 侧栏目录来自 `TOC.md`（分组、拖拽、完成态）
- 视觉编辑 / 源码编辑同一篇 Markdown
- 配置页改 `tnotes.json`（名称、图标、端口、Pages、统计）
- 内嵌站点预览（端口见 `tnotes.json` 的 `port`，本库是 `10107`）

### 6.2. 命令行只做无界面的事

| 脚本              | 实际命令             | 用途                                 |
| ----------------- | -------------------- | ------------------------------------ |
| `pnpm tn:update`  | `tnotes-kb update`   | 回填近 12 个月完成数到 `tnotes.json` |
| `pnpm tn:build`   | `tnotes-ssg build`   | 静态站，产物在 `.tnotes/dist`        |
| `pnpm tn:dev`     | `tnotes-ssg dev`     | 无 Desk 时的本地站点                 |
| `pnpm tn:preview` | `tnotes-ssg preview` | 预览已构建产物                       |

新建知识库、新建笔记、改目录，优先在 Desk 里做。`tnotes --*` 那套 core CLI 已停用。

### 6.3. Markdown 扩展

- `swiper` 图片轮播
- `mindmap` 思维导图
- Mermaid、数学公式、代码组、Footprints 等

### 6.4. 评论功能

利用 Giscus 集成了评论功能。映射键是笔记 frontmatter 里的 `id`（UUID），迁移时不要重生成。

## 7. TNotes 中「知识库」的类型及其之间的关系是？

目前在 TNotes 中只有两种类型的知识库：「根知识库」和「子知识库」。

- 根知识库：只有一个，汇总所有子知识库的目录信息，充当统一访问入口
- 子知识库：可以有多个，每个子知识库独立访问、独立部署
