## 1. 本节内容

- `tn:update` 现在做什么

## 2. 评价

`tnotes --update` 以前会改笔记正文、目录、sidebar。现在的 `tnotes-kb update` **只回填统计**，不动笔记正文。

```bash
pnpm tn:update
# 等价于
pnpm exec tnotes-kb update
```

前提：`tnotes.json` 里 `"stats": { "enabled": true }`，并且这是一个 git 仓库。它读 `TOC.md` 的完成态和 git 历史，写入 `stats.completedNotesCount`。

目录、完成勾选、标题，都在 Desk 里改 `TOC.md` / 笔记文件，不要指望 `tn:update` 再扫一遍旧的 README。
