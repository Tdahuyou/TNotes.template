## 1. 本节内容

- 本地预览知识库站点

## 2. 评价

日常写笔记请用 Desk。Desk 打开知识库后，站点预览走 `tnotes.json` 里的 `port`（本库 `10107`）。

没有 Desk、只要静态站热更新时，再用 `tnotes-ssg dev`。

## 3. Desk 里怎么预览？

1. 用新 Desk 打开工作区（已迁移库所在的 `kbs/` 目录，或直接打开单个知识库）。
2. 选中该知识库，打开站点预览。
3. 浏览器访问 `http://localhost:<port>/<name>/`，例如本库 `http://localhost:10107/TNotes.docs/`。

未迁移的旧库不要用新 Desk 打开（旧布局是 `notes/NNNN. 标题/README.md`）。

## 4. 命令行启动站点

知识库根目录需要有 `package.json`（创建知识库时勾选「添加 CLI / package.json」，或自己装 `@tnotesjs/ssg`）：

```bash
pnpm tn:dev
# 等价于
pnpm exec tnotes-ssg dev
```

端口和 base 读 `tnotes.json` 的 `port` / `base`。

## 5. 和旧命令的区别

旧的 `tnotes --dev` / VitePress HMR / 笔记目录监听服务已经去掉。文件监听和编辑由 Desk 负责；`tnotes-ssg dev` 只负责把当前 Markdown 编成站点。
