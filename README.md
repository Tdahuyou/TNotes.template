# TNotes.docs

## 简介

[TNotes.docs][1] 是 [tnotesjs/core][3] 的使用说明文档，主要记录以下内容：

- TNotes 核心组件的基本使用说明 + 功能演示
- TNotes 核心命令的基本使用说明
- TNotes 知识库配置文件和笔记配置文件的介绍
- TNotes 架构以实现原理简介
- TNotes 的一些迭代 Log
- ……
